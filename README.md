# Arduino Wind Tunnel Balance (Servo + Dual Load Cell)

This project implements a wind tunnel balance controlled by an Arduino.

## Features
- Servo-controlled angle of attack (15° increments)
- Calibrated mapping from servo angle to physical AoA
- Dual-axis force measurement (lift and drag)

The data from the arduino terminal can be easily copied and logged or directly imported into Excel.

## Motivation
This project was built to explore aerodynamic force measurement and automated testing workflows similar to those used in experimental aerospace engineering.
